## 📦 Getting Started Locally

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## 🚢 Deploy to Vercel via GitHub

1. **Commit and Push to GitHub**:
   ```bash
   git add .
   git commit -m "Initial commit: Brands Headquarter high-conversion web platform"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   git push -u origin main
   ```

2. **Deploy on Vercel**:
   - Go to [vercel.com](https://vercel.com) and sign in.
   - Click **Add New Project** and select your GitHub repository.
   - Next.js is automatically detected; click **Deploy**.
   - Your site will be live with free global CDN and automatic SSL.
